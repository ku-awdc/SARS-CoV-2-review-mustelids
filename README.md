# SARS-CoV-2-review-mustelids
Data supporting publication: A systematic review of key parameters for SARS-CoV-2 transmission in experimental studies on mustelids.

This repository contains the data extraction tables and analysis code for a scientific study reviewing transmission parameters of SARS-CoV-2 in mustelids (e.g., mink, ferrets, otters where applicable).

## Contents
- Curated extraction dataset of transmission-related parameters reported in the literature
- Reproducible analysis scripts to generate tables/figures used in the manuscript
- Documentation of variable definitions and data provenance
